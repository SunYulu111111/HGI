# yngg 本地 Python Spin 性能审核

历史记录说明（2026-10-23）：下列计时及逐调用一致性结果来自新 Bonus 规则加入前。当前已增加整轮最多3个四叶草、每批新翻牌至少1枚普通金币的限制；运行结构优化继续保留，但此处3.70倍及RTP一致性结论仅对应2026-10-22版本。当前规则尚未重新计时或校准RTP。

日期：2026-10-22。本轮只调整运行结构，35份配置、当前RTP权重、免费次数和抽取规则均未修改。原有 `simulation.py` 入口直接使用优化后的 `ThemeMath`。

## 实测结果

同机、同一套配置、相同种子，对优化前后交替计时。每批5000局付费Base，并完整执行所有触发的普通Free、Super Free及重触发；共3批。初始化不计入循环时间，不带分析器或随机调用追踪。

| 指标 | 优化前 | 优化后 |
| --- | ---: | ---: |
| 每5000局平均耗时 | 9.222秒 | 2.491秒 |
| 平均吞吐 | 542付费局/秒 | 2008付费局/秒 |

整体约加速 **3.70倍**。单批旧版/新版耗时详见 `spin_performance.json`；绝对速度受机器负载、Python版本及路径所在文件系统影响。这是本地Python完整Spin，不是原生C++校准器速度。

## 热点与结构调整

定位样本为2000局付费Base。优化前约76%的累计时间落在Cluster判奖，`cal_item_list`被调用9,345次；统计/报表层自身耗时不到1%，因此保留 `simulation.py`，没有引入第二套统计口径。

1. **单次扫描分类图标。** 原来每个普通图标都重新扫描全盘并检查禁用格。现在一次扫描建立各图标候选，保留原来集合插入及连通组件扫描顺序，提前跳过不足起奖数量的候选。
2. **同一盘面共用分析。** `_analyze_special_board`统一提供判奖结果和可替换位置，初始数量选择、特殊图标放置与首轮消除复用同一结果。补牌后的候选分析继续交给下一轮消除使用。分析仅在当前盘面流程内传递，不长期缓存随机盘面。
3. **缓存静态概率参数。** TYPE激活复用已校验的参数；通过原始配置节和DEFAULT快照识别原地变更，切换类型仍恢复正确参数。权重抽样使用有界累计权重缓存与二分查找，保留相同的 `random.randrange(total)` 请求。
4. **按需构造明细。** `return_detail=False`时不构造最终会被丢弃的消除盘面副本及逐轮日志；用独立计数保留 `cascade_count`。奖金、免费状态、金色玩法和公开返回字段保留。

相同定位样本中，判奖调用降至 **3,252次**。自定义特殊ID若能付费或充当Wild，将重新判奖；替换旧Wild也会重新计算，避免金额相同但组件顺序改变。既有严格轴文件检查、异常与普通/超级免费语义保留。

## 一致性验证

- **79项单元测试通过**，包含配置原地变更、DEFAULT插值变更、权重边界，以及自定义付费图标/Wild替换后的金额和明细顺序。
- **20,000局付费Base逐调用差分**，覆盖TYPE 0/4/8/12/17及两种明细模式，并完整执行1,124次Free Spin，其中100个普通Free和4个Super Free session。
- **243,978次随机请求完全相同**；每次Base/Free的完整结果、`last_win_*`、`last_spin_state`、`last_ng_result`、`last_fg_result`以及随机结束状态均一致。
- 三轮计时的六项累计奖金、触发次数、免费次数及最终随机状态一致；另有5000局完整模拟报告行及status与优化前完全一致。
- 全部35份配置及原有模拟CSV逐字节不变。RTP校准报告中的源代码哈希仍记录原采样版本，本次等价性验证作为补充关联，未将旧采样冒充为新代码重新采样。

## 复现

在 `ThemeMath/yngg` 下运行当前版本基准：

```sh
python3 -B benchmark_spin.py --spins 5000 --runs 3 --seed 2026102261
```

保留优化前的 `theme_math.py` 时，可以执行计时和默认2万局严格差分：

```sh
python3 -B benchmark_spin.py --spins 5000 --runs 3 --seed 2026102261 --reference /path/to/original/theme_math.py --output /tmp/yngg-performance.json
```

参考文件路径由调用者提供；两个版本统一读取当前工程配置。重现历史逐调用对比时，必须配套使用变更前配置与两份变更前规则实现；当前实现新增了Bonus规则，不能与旧规则实现要求随机序列完全一致。脚本只返回或保存JSON，不写入模拟CSV。性能数值不作为单元测试阈值。
