# 《Si Botak Desa》玩法介绍

## 游戏概述

《Si Botak Desa》采用 6 列 × 5 行盘面和 Cluster Pays 玩法。相同普通图标在水平或垂直方向相邻时形成 Cluster，至少 5 个图标即可中奖，Cluster 越大，奖励越高。

Wild 可以加入任意普通图标的 Cluster，但不能单独组成中奖。

## Cluster 消除

中奖 Cluster 完成赔付后会被消除，保留图标维持相对顺序，并从同一轴当前窗口后方继续补充新图标；随后继续判断新的 Cluster，直到盘面不再中奖。

当某一种普通图标形成中奖 Cluster 时，盘面上其他未参与该 Cluster 的同种普通图标也会一并消除：

- 只有实际组成中奖 Cluster 的图标参与赔付。
- 只有实际组成中奖 Cluster 的位置生成金色区域。
- 额外消除的同种图标不增加奖励，也不生成金色区域。
- 未参与中奖的 Wild 不会因为该规则被额外消除。

## Scatter 与 Super Scatter

单次 Base Spin 最多出现 3 个 Scatter 类图标，并且最多出现 1 个 Super Scatter：

- 可能出现 3 个普通 Scatter。
- 可能出现 2 个普通 Scatter和 1 个 Super Scatter。
- 不会同时出现 3 个普通 Scatter和额外的 Super Scatter。

Base 出现 3 个普通 Scatter 时触发普通免费游戏；出现 2 个普通 Scatter和 1 个 Super Scatter 时触发超级免费游戏。

## 普通免费游戏

普通免费游戏初始获得 10 次 Free Spin。

- Free 中不会出现 Super Scatter。
- 单次 Free Spin 最多出现 3 个普通 Scatter。
- 出现 2 个 Scatter 时追加 2 次 Free Spin。
- 出现 3 个 Scatter 时追加 4 次 Free Spin。

进入普通免费游戏时不带入 Base 盘面的金色区域。普通免费游戏中的实际中奖位置会持续累积为金色区域，额外消除的位置不加入。金色区域会保留到触发金色玩法或本轮普通免费结束；触发金色玩法后，已累积的金色区域清空。

## 超级免费游戏

超级免费游戏初始获得 10 次 Free Spin。

- 进入条件为 2 个普通 Scatter和 1 个 Super Scatter。
- 进入玩法后不会继续出现 Super Scatter。
- 单次 Spin 最多出现 3 个普通 Scatter。
- 出现 2 个 Scatter 时追加 2 次；出现 3 个 Scatter 时追加 4 次。

进入超级免费游戏时不带入 Base 盘面的金色区域。超级免费游戏中的金色区域会持续累积。触发金色玩法后金色区域仍然保留，直到本轮超级免费结束才清空。

普通免费和超级免费均会在整轮玩法尚未出现 Bonus 时，于最后一次 Free Spin 的全部消除结束后，在有可替换普通图标的终盘尝试补入一个 Bonus。

Free 初始盘面先生成 Scatter，只有实际放入不超过 2 个 Scatter 且仍有可替换位置时，才继续判断 Bonus。2 个 Scatter 的追加次数和 Bonus 可以同时生效；3 个 Scatter 时跳过初盘 Bonus 生成，末局终盘保底另行判断。

## 金色玩法

普通图标的实际中奖位置在消除后变为金色区域。全部消除结束后，如果金色区域非空且盘面仍存在 Bonus，触发金色玩法。每次 Base 从空的金色区域开始：有消除时才可能触发 Base Bonus；没有消除时也可能出现 Bonus 图标，此时仅展示，不触发金色玩法，也不产生 Bonus 奖励。

Base 盘面已有 3 个 Scatter 类图标时不再生成 Bonus；出现 Bonus 时，后续掉落不再生成新的特殊图标，因此免费游戏与金色玩法不会在同一 Base Spin 同时触发。

金色玩法中，每个金色位置会生成以下一种结果：

- 铜币：提供 0.2x、0.5x、1x、2x、3x 或 4x 奖励。
- 银币：提供 5x、10x、15x 或 20x 奖励。
- 金币：提供 25x、50x、100x、250x 或 500x 奖励。
- 四叶草：以自身为中心，对九宫格范围内的金币和已结算聚宝盆进行 2x、3x、4x、5x、10x 或 20x 放大；JP 不受影响。
- 聚宝盆：收集当前金色区域内的金币和已结算聚宝盆，不收集 JP，并使其他位置重新生成结果。
- JP：直接获得 MINI 10x、MINOR 25x、MAJOR 100x 或 GRAND 5000x。

同一轮先结算全部四叶草，再按列从左到右、每列行下标从 4 到 0 的固定顺序结算聚宝盆。所有已结算聚宝盆会继续保留，其余位置重新生成；如果再次出现聚宝盆，则继续重翻，直到没有新的聚宝盆。

一整轮金色玩法累计最多出现 5 个聚宝盆、3 个四叶草。达到对应上限后，后续位置不再生成该类型。首次翻牌及每次聚宝盆结算后的重翻中，新翻出的图标至少有 1 枚普通金币（铜币、银币或金币）；此前保留的聚宝盆不计入。累计上限仅针对本次金色玩法及其全部重翻，结束后重置；超级免费保留金格，但下一次独立触发的金色玩法会重新计数。

金色玩法最终奖励为当前金币与聚宝盆金额之和，再加上过程中获得的全部 JP 奖励。

## 押注档位

游戏支持以下 8 个押注档位：

- 100,000
- 200,000
- 500,000
- 1,000,000
- 2,000,000
- 5,000,000
- 10,000,000
- 20,000,000


## 当前规则与历史数值目标

聚宝盆、四叶草累计上限及每批新普通金币保底适用于所有 TYPE 的金色玩法。普通和超级免费保留初始 10 次及原有追加规则；500x 金币、20 倍四叶草和 GRAND 5000x 等高档奖励继续存在。TYPE 0 当前 Base 自身有奖概率目标为 30%、消除 RTP 目标为 40%，Base Bonus 触发概率目标为每次付费 Base 约 1.25%，Base Bonus RTP 目标为 20%。常见中档金币的出现机会增加，所有高档奖励仍然保留。

2026-10-22 TYPE 0 的历史目标总 RTP 为 95%：Base 消除 45%、Base Bonus 20%；普通 Free 消除约 7.3%、Bonus 18%；Super Free 消除约 0.7%、Bonus 4%。Base Bonus、普通 Free、Super Free 的历史目标触发率分别约 1.25%、0.5%、0.05%。RTP 均以付费 Base 累计押注为分母。

当前实测见 `bonus_type_calibration.json`。TYPE 0 的三种模式共用 Bonus 奖励概率，因此免费 Bonus 与总 RTP 也随奖励分布变化；10 月 22 日的历史免费分项及总 95% 结论不用于当前参数。RTP 是长期统计口径，不保证单个玩家或短样本结果。技术参数及 `[GENERAL]` / `[Type0]` 读取关系见 `PARAMETERS.md`。
