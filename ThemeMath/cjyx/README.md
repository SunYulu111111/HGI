# 超级英雄 cjyx

《超级英雄》（Heroes’ Fight），游戏 ID 373。机台采用 5 列 5 行、19 条固定赔付线，核心玩法为特殊 Wild 向下延展、融合普通 Wild 形成倍数，以及超级免费游戏的列激活。

本项目用于维护玩法介绍和数值逻辑。本轮机制规则与统计口径已完成逐项确认，并同步至两份文档；具体轴带、正式权重和精确数值目标保留为后续数值设计事项。
